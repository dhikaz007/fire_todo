# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-12-24

### Added
- **Authentication**: Initial release with Sign Up, Login, and Logout features.
- **Email Verification**: Added security layer to verify user email addresses.
- **Todo Core**: 
    - Create new tasks.
    - Edit existing task titles.
    - Delete individual tasks.
- **Bulk Operations**: Added "Delete All" feature to clear the entire list at once.
- **Profile**: Basic user profile page to view account details.
- **Real-time Sync**: Integration with Firebase Firestore for instant data synchronization across devices.
- **Documentation**: 
    - Added Privacy Policy (Markdown).
    - Added About Page with versioning and licenses.

### Fixed
- Fixed "Unable to load asset" error by correcting the path in `MarkdownPageListTile`.
- Optimized Firestore read/write operations for better performance.
